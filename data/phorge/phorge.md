## Overview

Phorge is a community-driven platform for collaborating, managing, organizing, and reviewing software development projects. It is a fork of Phabricator.

## Features

- Code review
- Task management
- Repository hosting
- Project organization
- Diffusion (repository management)
- Maniphest (task tracking)
- Differential (code review)
