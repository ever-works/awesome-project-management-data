## Overview

Gitea is a painless all-in-one software development service, including Git hosting, code review, team collaboration, package registry and CI/CD. It is a lightweight, community-driven fork of Gogs.

## Features

- Git hosting and repository management
- Code review
- Team collaboration
- Package registry
- CI/CD
- Issue tracking
- Pull requests
