## Overview

Fossil SCM is a simple, high-reliability, distributed free and open-source software configuration management system with integrated bug tracking, wiki, and project management features.

## Features

- Distributed version control
- Bug and issue tracking
- Integrated wiki
- Project management
- Self-hosting web interface
- Single executable distribution
