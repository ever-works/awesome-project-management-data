## Overview

Ideon is a project workspace built around an infinite canvas. It enables teams to embed repositories from GitHub, GitLab, Gitea, and Forgejo alongside notes, links, and tasks with real-time collaboration.

## Features

- Infinite canvas workspace
- Repository embedding (GitHub, GitLab, Gitea, Forgejo)
- Notes and links
- Task management
- Real-time collaboration
