## Overview

Paymo is a project management platform built for teams that manage client work, combining project tracking, time tracking, invoicing, and billing in one tool.

## Features

- Project setup per client with billable (hourly rate or flat fee) or non-billable options
- Built-in timer to track time spent on each task and project
- Automatic invoice generation based on tracked time
- Five view options: list, table, Kanban board, Gantt chart, and calendar
- Filter tasks across all clients and projects by status, due dates, and priorities
- Timesheets, team communication, and file storage per project
- Customizable user roles
- Native integrations (limited set) plus Zapier connectivity for thousands of other tools

## Pricing

- **Free plan**: Unlimited invoices and tasks, 1 user, 2 projects, 1 client
- **Solo plan**: From $5.90/user/month, includes 5 projects and 3 clients plus additional view options

## Deployment

Cloud-based SaaS (Web, macOS, Windows, Linux, iOS, Android)

## Integrations

Native integrations available; Zapier integration connects with thousands of other apps including accounting and calendar tools.
