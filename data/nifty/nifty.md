## Overview

Nifty is a project management platform offering a streamlined, Notion-like experience with robust project-focused features including customizable views, user permissions, time tracking, and team collaboration.

## Features

- Project templates across departments and use cases
- Import projects and tasks from other project management tools
- Streamlined project dashboard with high-level project outline, members, and recent activity
- Roadmap view for milestones, scheduling, and percent completion
- Seven view options: Kanban, list, calendar, swimlane, timeline, report, and roadmap
- Set default view per project and toggle between views
- Task comments and project-wide Discussions for team collaboration
- Granular user permissions with custom role creation
- Over a dozen native integrations plus Zapier connectivity
- Time tracking and budget tracking (paid plans)

## Pricing

- **Free plan**: Unlimited users, 2 active projects
- **Personal plan**: From $7/user/month (paid annually), includes 2 guests/clients per seat, up to 40 projects, custom fields, time and budget tracking

## Deployment

Cloud-based SaaS (Web, macOS, Windows, iOS, Android)

## Integrations

Native integrations (12+); Zapier integration for connecting with thousands of additional tools.
